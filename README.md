## ✨ Features

- 🎯 **Real-Time ATS Scoring (0–100%)**: Instant evaluation measuring Keyword Density, Quantifiable Metrics, Action Verb Strength, and Structure.
- 🔍 **Automated Keyword Gap Analysis**: Compares your resume against any target job description and flags critical missing keywords with a 1-click add button.
- 🤖 **Google XYZ Formula Bullet Optimizer**: Uses AI and rule-based NLP to rewrite passive bullet points into high-impact accomplishments (*"Accomplished [X] as measured by [Y], by doing [Z]"*).
- 🚀 **1-Click "Accept Rewrite"**: Effortlessly replaces weak bullets inside your resume with a single click.
- 📑 **Multi-Format Export**: Export your optimized resume to `.txt`, `.md`, or directly print / save as PDF.
- 🎨 **Modern Dark Glassmorphism UI**: Beautiful, responsive interface with fast local performance.

## 🚀 Quick Start

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/ruthikph2-jpg/ResumeForge-AI.git
cd ResumeForge-AI
\`\`\`

### 2. Install dependencies
\`\`\`bash
npm install
\`\`\`

### 3. Start development server
\`\`\`bash
npm run dev
\`\`\`

Open [http://localhost:3001](http://localhost:3001) in your browser.

## 🌐 Deploy to Vercel

1. Push this repository to GitHub under your profile (`ruthikph2-jpg`).
2. Log into [Vercel](https://vercel.com) and import `ResumeForge-AI`.
3. Framework Preset: **Vite**
4. Click **Deploy**! 🚀
